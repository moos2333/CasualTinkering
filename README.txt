Casual Tinkering
================

A Tinkers' Construct 3 addon for Minecraft 1.20.1 (Forge).

Content
-------
- Circular Saw: a hand axe / melee hybrid with a charged spinning sweep attack (Sawing modifier).
- Magic Sword: four modifiers (strike / control / auto / coop) that summon homing magical swords.
- Throwing Knife: a data-driven shuriken with a sneak triple-shot spread.
- Boomerang: a returning thrown weapon (Boomerang modifier).
- Heat Ray Gun: a fluid-fueled beam weapon that overheats after sustained fire.

This project is a port and merge of the author's 1.12.2 Casual Tinkering addon and
the Tinkers Gadgets mod, rebuilt around Tinkers' Construct 3's modifier hooks and
data-driven tool definitions.

Building
--------
Requires JDK 17. Run `./gradlew build` (uses the configured offline Gradle setup).
Dependencies: Tinkers' Construct, Mantle, Json Things (CurseMaven); JEI at runtime.
